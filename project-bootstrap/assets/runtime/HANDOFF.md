# 交接

不同AI/产品共用AGENTS、索引、状态和正式记录。向接手者明确打开这些本地文件；平台是否自动加载由该平台决定。不要把整个旧对话/所有记忆放进新的上下文。

最小交接：实际请求与授权、角色、工作单与入口门、输入版本/哈希、结果与验证范围、失败/假设、未决事项及下一步。交接消息不能替代用户新的授权。

后继创建新任务并引用前驱TASK-id。前驱仍在写入时不接管它的目录；需要交出工作区时先记录并停止写入。正式状态可能滞后，先核对最近任务事件与产物，再由维护者更新里程碑。

只读一个相关工作单及必要方法/证据；重大路线改变准备具体审查包，常规实现自主完成。经验/状态收尾见 [MEMORY_WORKFLOW.md](MEMORY_WORKFLOW.md)。
