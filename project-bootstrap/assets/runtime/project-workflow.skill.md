# 分包执行

读取[入口](../../AGENTS.md)、[状态](../../context/STATUS.json)，从[catalog](../../context/catalog.json)取一个工作单及相关spec节。目录是位置索引，实际授权来自当前用户请求；未知输入/依赖如实记录。

先核对最早依赖门及当前软件/数据证据，按需加载领域skill。规划命令不是已有程序；实现后小样例验证实际行为，再在报告中给出真实可重算命令、产物与对应验收。

安装、框架、运行及领域验收是不同检查范围；最终目标按其证据通过。失败日志/输出留在独立任务/运行目录，输入与参数有版本，不能覆盖成功结果来掩盖反例。

常规实现在已授权任务内完成，重大目标/方法/正式契约变化准备具体审查。完成后按[project-memory](../project-memory/SKILL.md)追加状态和必要经验；宏观状态滞后时提供证据给维护者更新。
