# Project Bootstrap · Codex 项目搭建

[English](README.en.md) | 简体中文

将用户需求转化为 Codex 可持续执行的本地项目，完成需求澄清、任务规划、项目框架与上下文搭建。适用于科研、软件、工程、数据分析等长期项目。

## 从需求到项目

你可以只描述想做什么。技能会澄清影响路线的必要问题，组织输入、方法、任务和验收，并实际搭建工作区，让后续 Codex 会话能知道目标、当前进度和下一步。

- 需求与任务：范围、成果、依赖、输入、执行动作和验收条件。
- 项目框架：目录、精简 AGENTS.md、资料索引、状态和交接文件。
- 环境与启动：检查工具、输入和依赖，在授权内准备环境并验证首个任务。
- 上下文与记忆：按需读取，本地保存来源、决定、候选经验和版本记录。

这里的 Codex 项目是本地工作区，不会自动注册到 Codex 应用的项目列表；搭建后需在应用中打开或添加该目录。生成器提供通用框架，专业程序和最终成果仍需按工作单实现、验证。

## 安装与使用

下载本仓库，将 project-bootstrap 文件夹复制到用户主目录的 .codex/skills/ 中。

向 Codex 输入：

```text
使用 $project-bootstrap。
我的需求：……
项目目录：……
已有资料或代码：……
请补齐影响执行的必要需求，搭建 Codex 本地项目并检查首个任务的执行条件。
```

入口：[SKILL.md](project-bootstrap/SKILL.md)；[英文核心说明](project-bootstrap/SKILL.en.md)。详细参考和生成模板目前主要为中文，英文核心说明不代表运行时已全部英文化。其他 AI 工具可以读取本地文件，但兼容性与加载方式需分别验证。

生成器默认预览；确认配置后使用 --apply，遇到已有文件碰撞会拒绝写入。支持已有项目的差距审查和小幅整合。

## 开发与验证

运行时使用 Python 3.10+ 标准库。开发校验依赖见 requirements-dev.txt。

```sh
python -X utf8 project-bootstrap/scripts/bootstrap_project.py --help
python -X utf8 project-bootstrap/scripts/test_bootstrap.py
```

测试使用模拟项目。框架检查通过不代表科研结论、业务需求或最终产物已验收；记忆审批记录不能代替权限隔离或身份认证。
